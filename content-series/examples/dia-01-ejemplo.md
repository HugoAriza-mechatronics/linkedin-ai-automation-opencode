Hoy: Git + GitHub

Git no es solo para programadores. Es la forma de registrar la historia de tu trabajo: qué cambió, cuándo y por qué. Cada confirmación es un punto de restauración, y cada rama es un espacio seguro para probar sin romper lo que ya funciona. 🔍

GitHub lleva eso a la nube y añade colaboración: revisiones, issues y proyectos. Para un equipo, significa que dos personas pueden trabajar sin pisarse. Para ti, significa que tu portafolio tiene evidencia real de cómo piensas y cómo iteras. ⚙️

Mi consejo: empieza con tres comandos — `status`, `add` y `commit` — y un repositorio privado. Lo demás llega solo cuando lo necesites. 📊

¿Tú ya usas Git en tus proyectos o sigues guardando versiones a mano? ¿Qué te costó más al principio? 👇
